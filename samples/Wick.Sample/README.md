# Wick.Sample

Blazor Web App (Interactive Server) that shows every Wick feature. Each component has a render counter, so you can see exactly what re-renders.

```sh
dotnet run
```

Then open http://localhost:5080.

Pages include a counter written from several threads, a 400-cell grid next to the classic event pattern, a live market fed by a background service, nested state, a todo list, and reactive regions.
